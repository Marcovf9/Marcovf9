### 🖨️ [MO Impresiones](https://github.com/Marcovf9/moimpresiones-ecommerce) — Catalog, Quotes & Admin Panel
**Live:** [moimpresiones.com](https://moimpresiones.com)

Website and quoting system for a print shop running since 1994. Customers build a multi-product request from the catalog and send it in one step: the quote is stored, the owner is emailed, and WhatsApp opens with the message already written. The owner runs the rest from the panel — catalog, photos, site texts, a searchable quote inbox and traffic reports. Catalog search is accent-insensitive over the entire spec sheet (`unaccent` + `pg_trgm`), analytics count visitors without cookies, and a post-build step writes one HTML file per route so a single-page app can be indexed and shared. 64 tests run on every push.

`Java 21` `Spring Boot 3.5` `Spring Security + JWT` `React 19` `TypeScript` `Tailwind 4` `PostgreSQL` `Flyway` `Cloudinary` `Docker` `GitHub Actions`
